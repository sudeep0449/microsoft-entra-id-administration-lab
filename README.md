# Microsoft Entra ID Administration Lab

## Lab Overview

A hands-on lab covering identity and access management using Microsoft Entra ID (Azure AD) in the Azure Portal. The lab covers user management, group management, administrative role assignment, password resets, multi-factor authentication (MFA), sign-in monitoring, and account lifecycle management.

## Environment

- **Platform:** Microsoft Entra ID, administered via the Azure Portal
- **Tenant:** Default Directory

## Topics Covered

- Microsoft Entra ID overview
- User management
- Group management
- Administrative role assignment
- Password reset
- Multi-Factor Authentication (MFA)
- Authentication methods
- Sign-in logs
- Account blocking and unblocking
- Deleted user management

## What Was Done

- Reviewed tenant groups (security groups, M365 groups, cloud vs. on-premises groups) under **Groups | Overview**
- Assigned and reviewed administrative roles (e.g. **User Administrator**) under **Assigned roles**
- Created and managed a test user account, reset its password, and signed in as that user to verify access
- Blocked and unblocked a user's sign-in access, then confirmed the account could sign in again after unblocking
- Reviewed sign-in logs and authentication methods for the account

## Conclusion

Successfully demonstrated practical administration of Microsoft Entra ID, including identity management, user lifecycle management, authentication security, and access control — core skills for IT Help Desk and Junior System Administrator roles working with cloud identity platforms.
